Glucose & Glucose Sensors

An interactive, self-contained teaching module: sugar chemistry, the structure of glucose, classical tests for glucose, and how a modern continuous glucose monitor works.

→ Main module → Inside a modern sensor No internet needed Phone · tablet · print

Pages

Main module

index.html

  1. Sugars & saccharides: classification, reducing vs non-reducing sugars, a sugar explorer with a self-quiz, and a zoom from starch to glucose
  2. Glucose: a 3D model (open chain, α/β pyranose, fructose), Fischer projections, an aldose ⇌ ketose (enediol) stepper, Haworth anomers and a mutarotation simulation
  3. Traditional tests: a virtual test-tube lab (8 tests × 7 samples plus a mystery sugar), colour keys, equations, a Benedict’s slider, an identification flowchart and a results matrix
  4. Advances: an interactive timeline from c. 500 BCE to 2024, a then-vs-now table and the sensor generations

Ends with a 6-question quiz and references.

Inside a modern glucose sensor

sensor.html (standalone)

  • Signal chain: blood → interstitial fluid → electrode → phone
  • Clickable cross-section of the on-body device
  • Three-electrode cell and an animated membrane-layer simulation
  • Glucose oxidase cycle (O₂ and mediator modes)
  • Current-vs-glucose simulator with an oxygen-deficit demonstration
  • Blood-vs-ISF lag simulator with trend arrows
  • MARD calculator, time-in-range targets and limitations
  • Sensor generations, a device comparison and what’s next

Using it

Offline / in class

Double-click index.html. All styles, scripts and molecule data are stored locally, so it works without internet. It also works on a projector, phone or tablet.

Share online with GitHub Pages

  1. Push this folder to a GitHub repository.
  2. Go to Settings → Pages.
  3. Choose Deploy from a branch, branch main, folder / (root).
  4. Share https://<user>.github.io/<repo>/ with students.
Tip: the ☾/☀︎ button switches dark and light mode, and every page prints cleanly for handouts.

Notes for instructors

  • The 3D coordinates are PubChem computed conformers (CIDs 107526, 79025, 64689, 5984, 439709).
  • The test-tube outcomes, membrane particle model, current-vs-glucose model and lag model are simplified for teaching. They show the right trends, but their numbers are illustrative.
  • Device specifications (wear time, reading interval) change often. Check current manufacturer labelling before teaching specific numbers.
  • Each page lists its references at the bottom. Superscript citations link to them.
The simulations are for teaching only and are not for clinical use.
